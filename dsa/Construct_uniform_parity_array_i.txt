from typing import List

class Solution:

    # Logic: Mathematical Parity Transformation (O(1) Time, O(1) Space)
    # 1. We are given an array `nums1` of distinct integers and need to form `nums2` where all elements have the same parity (all odd or all even).
    # 2. For each index `i`, we can either:
    #    - Keep `nums2[i] = nums1[i]`, OR
    #    - Set `nums2[i] = nums1[i] - nums1[j]` for any `j != i`.
    # 3. Consider the parity rules:
    #    - Even - Odd = Odd
    #    - Odd - Even = Odd
    # 4. If `nums1` is already uniform (all even or all odd), we keep `nums2[i] = nums1[i]` for all `i`.
    # 5. If `nums1` contains a mix of both even and odd elements:
    #    - There exists at least one odd element `nums1[j]`.
    #    - For every even element `nums1[i]`, we can transform it to odd by setting `nums2[i] = nums1[i] - nums1[j]`.
    #    - For every odd element, we keep `nums2[i] = nums1[i]`.
    #    - Since there are no positivity constraints in Part I, this transformation is always valid.
    # 6. Therefore, it is always possible to construct an array with uniform (odd) parity.
    # 7. Hence, we can always return `True`.
    #
    # Time Complexity: O(1)
    # Space Complexity: O(1)
    #
    # Dry run for nums1 = [2, 5, 8]:
    # - Contains evens: [2, 8] and odd: [5].
    # - For 2: choose j pointing to 5 -> nums2[0] = 2 - 5 = -3 (Odd).
    # - For 5: keep nums2[1] = 5 (Odd).
    # - For 8: choose j pointing to 5 -> nums2[2] = 8 - 5 = 3 (Odd).
    # - Resulting nums2 = [-3, 5, 3] (all odd).
    # - Returns True.
